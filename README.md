# Mivella Fashion — E-Commerce Website

## Overview

WebMivella is a business website developed for Mivella Fashion to support the digitalization of its product presentation and customer ordering process.

The project applies web development technologies to address a real business need by providing customers with an accessible way to explore products and place orders.

## Project Objective

The website was developed to:

- Digitalize product presentation for Mivella Fashion.
- Provide customers with an accessible product browsing experience.
- Simplify the customer ordering process.
- Create a responsive and user-friendly interface.
- Apply technology to improve a small business's digital sales process.

## Key Features

- Product catalog and product presentation
- Responsive website interface
- Customer ordering flow
- Interactive website elements
- Structured product information
- User-friendly customer experience

## Technologies

- **HTML5** — Website structure
- **CSS3** — Styling and responsive interface
- **JavaScript** — Interactive functionality
- **ASP.NET / C#** — Web application framework and project structure
- **Visual Studio** — Development environment
